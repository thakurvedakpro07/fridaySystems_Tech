{% comment %} Bulletproof CTA button — the canonical single-anchor pattern (Campaign Monitor / Litmus "bulletproof button"), not a custom nested-table construction. No flexbox, no CSS variables, no external stylesheet dependency for appearance: every visual property (background, radius, color, padding) is inline on the elements themselves. Outlook desktop gets a real VML roundrect (its Word engine ignores CSS border-radius and can mis-clip click targets and is hidden from every other client via mso-hide:all on the plain anchor); every other client (Gmail web/Android/iOS, Apple Mail, Yahoo, ...) renders the plain directly — no wrapping /
around it, because a real Chromium DOM inspection (see project notes) proved every inline declaration already computes correctly in isolation, so the previous nested table+td+span+class construction was strictly more complexity than the color bug needed; removing it rules out nesting depth as a variable entirely. Color is applied redundantly on the anchor AND both spans AND a legacy around each (four independent declarations of white per piece of text) — none of them rely on inheritance from a parent. `!important` is kept on the inline declarations only to survive this file's own dark-mode media query in base.html (a real, local specificity fight); the `btn-link` class is carried along purely as an optional extra CSS hook (dark-mode override + a Gmail-DOM-only selector in base.html) and is not required for the button to render correctly — every inline declaration here is independently sufficient on its own. Params: button_url, button_label — pass the label WITHOUT a trailing arrow; this component appends its own arrow in a second span/font pair.
