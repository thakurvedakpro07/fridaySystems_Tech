{% comment %} Info card — replaces hand-rolled meta-box/meta-row markup shared by every ticket/notification email. Rows are plain include params (Django's {% include %} can't take a list-of-dicts literal without a custom template tag, so this stays a flat, vanilla-template component): row1_label/row1_value/ row1_badge_color/row1_badge_bg, row2_*, ... up to row6_*. Badge params are optional — a row renders as a plain value unless *_badge_color is set. Omit unused rowN_label to skip a row. Usage (must stay on one line — Django template tags cannot span multiple lines): {% include "email/components/_info_card.html" with row1_label="Ticket" row1_value=ticket_number row2_label="Status" row2_value="Open" row2_badge_color="#4338ca" row2_badge_bg="#EEF0FD" %} {% endcomment %}
