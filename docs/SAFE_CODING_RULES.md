Before making any code changes:

1. Explain what you plan to change
2. List files affected
3. Explain risks
4. Avoid unnecessary rewrites
5. Avoid deleting working code
6. Prefer minimal targeted edits
7. Ask before large refactors
8. Preserve existing architecture unless improvement is necessary
9. Keep implementation beginner-friendly
10. Ensure new code integrates with existing code cleanly

After coding:

1. Explain what changed
2. Explain why
3. Provide testing steps
4. Update BUILD_PROGRESS.md
5. Suggest git commit message
